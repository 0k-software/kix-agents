# Route Request/Pitch/Task creation through Kix CLI

Eventually, all creations of Requests, Pitches, and Tasks should go through the
Kix CLI rather than being written directly by a skill. That gives us a place to
enforce consistency checks and invariants so creation is deterministic instead
of stochastic.
