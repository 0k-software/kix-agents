# acceptance-criteria

**Reads.** The branch's bead — its acceptance criteria and design, in the
brief's data — against the diff and the session.

**Delta.** New commits other than Fix commits, `rebased since <short>`,
`dirty tree`, or `<id> updated` when the bead itself changed. Re-judge the
items the delta could have changed.

**Findings.** Category `acceptance`: each design item and acceptance criterion
that the diff and the session do not deliver, or deliver only in part. Say
which item it is and what is missing.
